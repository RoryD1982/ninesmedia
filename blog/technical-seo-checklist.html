SEO & AI Search

Technical SEO Checklist for South African Websites

By Brandon Howard 3 November 2026 4 min read
Key takeaways
  • Technical SEO makes sure Google can find, crawl, understand and index your pages.
  • Start with Search Console's Page indexing report — it shows the biggest problems.
  • Canonical tags, redirects and internal links cause more ranking problems than most owners realise.

Great content can't rank if Google can't access it properly. Technical SEO covers the behind-the-scenes setup that lets search engines crawl and index your site. Use this checklist to review yours.

Indexing

  • Search Console is verified and the Page indexing report reviewed.
  • Important pages are indexed; "Discovered — currently not indexed" and "Crawled — currently not indexed" pages investigated.
  • No important pages blocked by robots.txt or a noindex tag.
  • An XML sitemap lists only canonical, indexable pages and is submitted in Search Console.

Canonicals and Duplicates

  • Each page's canonical tag points to its own preferred URL — exactly the URL used in links and the sitemap.
  • One version of the site resolves: https and either www or non-www, with redirects from the others.
  • No near-duplicate pages competing for the same search.

A mismatched canonical can stop pages being indexed entirely — we've seen it on real South African sites, including our own early version.

Site Structure and Links

  • Important pages are reachable within a few clicks from the home page.
  • Navigation uses real links (not only JavaScript click handlers).
  • No broken internal links; old URLs redirect with 301s to the best replacement.
  • Related pages link to each other with descriptive anchor text.

Speed and Mobile

  • Pages pass or are close to passing Core Web Vitals on mobile.
  • Images are compressed and sized correctly.
  • Unnecessary scripts and plugins removed.
  • Layout works on small screens without horizontal scrolling.

See website speed for South African-specific tips.

On-Page Technical Elements

  • Unique title tag and meta description on every page.
  • One H1 per page, with a logical heading structure.
  • Descriptive alt text on meaningful images.
  • Structured data valid where used — see schema markup.
  • Correct language and locale settings (en-ZA where relevant).

Security and Health

  • Valid SSL certificate.
  • No security issues or manual actions in Search Console.
  • CMS, themes and plugins up to date.

Beyond Google

Verify your site in Bing Webmaster Tools too — Bing powers Microsoft's search and is used by some AI assistants. Consider IndexNow for faster updates on Bing. See AI search visibility.

Frequently Asked Questions

What is technical SEO?

The setup that lets search engines crawl, understand and index your site: indexing, canonicals, sitemaps, site structure, speed, mobile usability and structured data.

How do I check if Google has indexed my pages?

Use Search Console's Page indexing report and the URL Inspection tool for individual pages.

Do canonical tags matter?

Yes. A canonical tag pointing to the wrong URL can stop a page being indexed or cause Google to choose a different version.
